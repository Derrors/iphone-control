# 自动解锁

默认关闭。开启后，手机锁屏时，MCP 操作前会先用你保存的锁屏密码解锁手机。截图、读元素、`iphone_wait_for` 这些只读工具也一样。WDA 不可用时不会自动解锁。

::: danger 先想清楚风险
密码以**明文**存在数据目录里。能登录这台主机、能读数据目录备份、或能调用这个 MCP 的人，都能解锁你的手机。只在你完全掌控的主机上开启，最好用一部专门用来自动化的手机。
:::

## 开启

首次运行 `iphone-control` 的引导里会问要不要设（可选），以后可以运行 `iphone-control setup --reconfigure` 选「自动解锁密码」。也可以直接用命令：

```bash
iphone-control passcode set
```

密码存给守护进程正在控制的那台设备；要给别的设备设，加 `--device <UDID 或设备名>`。只支持 4 位以上的纯数字密码。关闭：

```bash
iphone-control passcode clear           # 正在控制的那台；别的设备加 --device
iphone-control passcode clear --all     # 所有设备
```

## 多台设备

密码**按设备分开存**（数据目录 `secrets/passcodes/<UDID>`），一台的密码不会输进另一台；没设密码的设备锁屏时要人工解锁。`devices` 命令（或 `iphone_list_devices` 工具）会标出每台有没有设。

旧版本只存一份密码（`secrets/passcode`），不知道是哪台的：升级后 USB 上只接着一台时，它自动归到那台名下；同时接着几台时不会用它，在要用的设备连着时重新 `passcode set` 即可。

## 保护规则

- 每按一位都核对密码栏的位数，对不上立即停止（没输完不算输错）；只有第一位没生效时会重来，最多 3 轮。
- 整串输完手机仍然锁着，就**立即停用**自动解锁并推送通知，不会第二次再试，因此不会累计输错触发抹掉数据。
- 从第 2 位起先写停用标记（数据目录的 `logs/UNLOCK-DISABLED`），确认解开或确认没输满才撤掉。所以输入中途出错、进程被杀，也会保持停用。
- 停用标记是**全局**的：一台失败，所有设备的自动解锁都停用。
- 手机重启后第一次解锁（BFU）必须人工完成，自动解锁不处理。
- 手机横放充电时会进入**待机显示**，那个界面调不出密码键盘，自动解锁会失败。开启自动解锁时，在「设置 → 待机显示」里把它关掉。

## 停用后恢复

先人工解锁手机。如果是密码错了（例如你改了锁屏密码），先更新密码，再恢复：

```bash
iphone-control passcode set
iphone-control unlock-reset
```

如果是输入中途出错、进程被杀，密码本身可能没错，确认无误后只运行 `unlock-reset` 就行。`unlock-reset` 不会核对密码，`passcode set`、`passcode clear` 也不会解除停用。不要靠删除 `logs/` 来恢复，那会撤掉这层保护。

::: tip 不想用自动解锁
可以在手机上把「设置 → 显示与亮度 → 自动锁定」设为「永不」，手机就不会自己锁屏。
:::
